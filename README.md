# 🌸 Gerenciador de Vendas - Pietra Acelerando

Aplicativo desktop desenvolvido para gestão simples e visualização mensal de vendas.

---

### ⬇️ Download para macOS

[![Download para macOS](https://img.shields.io/badge/Download-macOS%20(.zip)-ffb6c1?style=for-the-badge&logo=apple&logoColor=white)](https://github.com/CezarHick/OrgVendas_proj/releases/download/1.0.0/GerenciadorDeVendas-macOS.zip)

> **Nota para usuárias de macOS:** Na primeira vez que for abrir o aplicativo, clique nele com o **botão direito** e selecione **Abrir** para autorizar o sistema.

---

### 📊 Como Funciona
- **Banco de Dados:** Conexão direta com a planilha `VENDAS PIETRA ACELERANDO.xlsx`.
- **Filtro por Mês:** Agrupamento automático de vendas por mês.
- **Edição/Exclusão:** Edição e remoção simplificadas diretamente na interface.
